# AssetFlow-Rheo
PROJECT OVERVIEW : 
AssetFlow is a centralized, enterprise-grade resource planning platform designed to simplify how organizations track, allocate, and maintain physical assets and shared resources. Moving away from fragmented spreadsheets and manual paper logs, AssetFlow provides real-time visibility into asset locations, ownership, and health states across an entire organization.

Core Features : 
1)Asset Lifecycle & DirectoryFull State Transitions: Tracks assets smoothly through multiple operational states: Available, Allocated, Reserved, Under Maintenance, Lost, Retired, and Disposed.  
2)Detailed History Tracking: Maintains an immutable per-asset log tracking historical allocations and maintenance events.  
3)Flexible Search: Multi-parameter filtering by Asset Tag (e.g., AF-0001), Serial Number, category, location, and condition.
